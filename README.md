# Smart Expense Tracker

A command-line personal finance application built with Python.

## Project Goals

This project is designed to help users:

- Record income
- Record expenses
- View current balance
- View transaction history
- Save financial data
- Load saved data

## Planned Features

- Add income
- Add expenses
- Calculate balance
- Store transactions in JSON
- Generate financial reports
- Export reports to Excel and PDF

## Technologies

- Python
- JSON
- Git
- GitHub

Currently under development.
